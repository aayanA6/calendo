# AI Calendar

An intelligent calendar application designed to boost productivity, organization, and personal accountability by using AI-powered scheduling assistance.

## Overview

AI Calendar helps users plan their time more effectively by combining a clean, modern calendar interface with AI-driven insights. It reduces mental load by organizing tasks, highlighting priorities, and supporting better daily decision-making.

## Key Features

* **Smart Event Management** – Create, edit, and manage events with ease
* **AI Productivity Assistance** – Intelligent suggestions to improve scheduling and time usage
* **Monthly Calendar View** – Clear, visually structured layout for long-term planning
* **Priority-Based Tasks** – Color-coded events for quick recognition
* **Dark Mode UI** – Minimal, distraction-free design optimized for focus
* **Fast Event Creation** – Add events in seconds with minimal input

## Use Cases

* Students managing exams, study sessions, and deadlines
* Professionals organizing work schedules and projects
* Individuals aiming to improve daily structure and consistency

## Tech Stack

* **Frontend:** React / Next.js
* **Styling:** Tailwind CSS
* **Icons:** Lucide Icons
* **State Management:** React Hooks
* **AI Layer:** Custom AI logic (task analysis & scheduling support)

## Getting Started

1. Clone the repository

   ```bash
   git clone <repository-url>
   ```
2. Install dependencies

   ```bash
   npm install
   ```
3. Run the development server

   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000` in your browser
